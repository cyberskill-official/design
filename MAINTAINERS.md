# Maintainers and contribution path

Stephen Cheng is the accountable owner and interim maintainer. The identity and
role registry is `components/maintainers.json`; `.github/CODEOWNERS` routes all
paths to his verified GitHub account. It does not appoint another reviewer,
create an independent review, or enable a required-review rule on GitHub.

Contributors can report a reproducible issue, propose a scoped change with its
contract/test/documentation evidence, then maintain an agreed area through
reviewed contributions. Becoming a maintainer or support reviewer requires an
explicit owner appointment recorded in the registry; contribution count and
agent implementation do not grant that authority. Security reports follow
`SECURITY.md`, and contribution steps follow `CONTRIBUTING.md`.

The recorded GitHub access check is a dated snapshot, not continuous permission
monitoring. Recheck eligibility before changing routing or relying on it for a
release. The observed main protection requires `fast-gates` and
`docs-consistency-blocker`; the returned settings do not require pull-request
reviews or Code Owner approval. Required review policy and remote protection
changes remain a separate owner action. Existing product visual review, manual
accessibility evidence and explicit push/deploy/merge authorization still apply.
