# Compiler facts and story domains

API extraction uses the public TypeScript 6 compiler API through the official `@typescript/typescript6` compatibility package. The package alias `typescript-api` pins the compatibility wrapper to `6.0.2`; its maintained lock resolves the actual compiler to `6.0.3`. The adapter checks both versions and the required public capabilities. TypeScript `7.0.2` remains the repository's declaration/consumer validation CLI. No source-language migration or validation downgrade is involved.

Microsoft documents this side-by-side arrangement in [Announcing TypeScript 7.0](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#running-side-by-side-with-typescript-6-0). TypeScript 7.0 has no stable checker API; production extraction must not import its `unstable/*` modules. Changing either API pin requires review, full index fact comparison, compiler fixture checks and strict React 18/19 consumer checks. `api-fact-comparison.mjs` preserves membership, optionality, authored/inherited provenance, descriptions and displayed structure. It normalizes union ordering only; tuple, parameter and intersection/overload order stay significant. Compiler display truncation remains a display boundary, not expanded type proof.

After declaration changes, run `node scripts/generate-api-index.mjs`, then `node scripts/generate-story-domains.mjs`. Run the same commands with `--check` for read-only freshness validation. The generated `stories/declared-domains.mjs` contains finite authored string/number unions in declaration order, including supported named aliases. CSF imports those arrays for controls and matrix axes. The resolver recognizes only the exact named generated-module import and literal property access; it never executes story expressions. Source hashes include the actual declaration graph and adapter/generator inputs. Unknown names, executable expressions and stale generated data fail validation.

The static guard still checks all supported runtime default expressions for declaration assignability and all finite authored domains for explicit controls or separately reviewed fixtures. Derived native `keyof` domains retain their content-model limits. Icon names retain their existing runtime-definition key authority. Browser tests additionally mount the actual Default and FullMatrix exports for Button, Badge, Link, ProgressBar and Skeleton: all their variant/size values, omitted defaults, native state behavior and semantic progress paint. Compiled-source negative controls reject ignored variants, an incorrect but type-valid default and a story that drops Controls args. This bounded evidence does not establish exhaustive runtime honoring, accessibility or semantics for every prop of every component.

# Dữ kiện trình biên dịch và miền giá trị của story

Bộ trích xuất API dùng API công khai của TypeScript 6 qua gói tương thích chính thức `@typescript/typescript6`. Alias `typescript-api` ghim gói bọc ở phiên bản `6.0.2`; lockfile được quản lý khóa trình biên dịch thực tế ở `6.0.3`. Adapter kiểm tra cả hai phiên bản và các khả năng API cần dùng. CLI kiểm tra khai báo và mã tiêu thụ vẫn là TypeScript `7.0.2`; không chuyển ngôn ngữ nguồn hay hạ cấp bước xác thực.

Microsoft mô tả cách chạy song song này trong liên kết phía trên. TypeScript 7.0 chưa có checker API ổn định; mã trích xuất dùng trong vận hành không nhập `unstable/*`. Khi đổi phiên bản, cần so sánh toàn bộ dữ kiện của index, chạy fixture trình biên dịch và kiểm tra consumer nghiêm ngặt với React 18/19. Bộ so sánh chỉ chuẩn hóa thứ tự union; thứ tự tuple, tham số và intersection/overload vẫn có ý nghĩa. Chuỗi hiển thị bị rút gọn không chứng minh toàn bộ kiểu đã được khai triển.

Sau khi đổi khai báo, chạy `node scripts/generate-api-index.mjs`, rồi `node scripts/generate-story-domains.mjs`; thêm `--check` để chỉ kiểm tra độ mới mà không ghi lại. Module story sinh tự động chứa các union hữu hạn do kho khai báo, theo đúng thứ tự khai báo. Controls và trục ma trận dùng chung các mảng đó. Bộ đọc chỉ chấp nhận import có tên từ đúng module và truy cập thuộc tính tĩnh; không thực thi biểu thức trong story. Hash nguồn bao phủ đồ thị khai báo cùng adapter và bộ sinh. Tên không tồn tại, biểu thức thực thi và dữ liệu sinh cũ đều bị từ chối.

Guard tĩnh vẫn kiểm tra khả năng gán của toàn bộ biểu thức mặc định được hỗ trợ và miền hữu hạn của các prop do kho khai báo. Miền `keyof` native giữ giới hạn mô hình nội dung; tên Icon vẫn theo các khóa định nghĩa runtime. Kiểm thử trình duyệt còn dựng Default và FullMatrix thực tế của năm component nêu trên, kiểm tra mọi variant/size tương ứng, giá trị khi bỏ prop, trạng thái native và màu token ngữ nghĩa của ProgressBar. Các đột biến mã được biên dịch phải bị bắt khi bỏ qua variant, đổi mặc định sang giá trị khác vẫn hợp kiểu, hoặc story làm mất Controls args. Phạm vi này không khẳng định đã kiểm thử toàn bộ prop, ngữ nghĩa hay khả năng tiếp cận của mọi component.
