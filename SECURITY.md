# Security policy

This repository holds a design system: tokens, CSS, React components and a static documentation site. There is no backend, database or authenticated API.

## Reporting a vulnerability

Report privately through [GitHub Security Advisories](https://github.com/cyberskill-official/design/security/advisories/new). Do not open a public issue for sensitive reports. We aim to acknowledge reports within 10 business days.

## Supported versions

| Version | Status |
|---|---|
| 3.x (`latest`) | Security fixes |
| 2.x (`legacy`) | Security fixes only, on the `legacy` branch, for a limited transition period |

Releases are published from CI with npm provenance.
