# Component contract template

Use this page as the anatomy for every **Stable** component. Fill each section; do not delete headings.

## Anatomy

Slots, semantic root, and composition.

## Usage

Do / don't. Default path first.

## States

Default, hover, focus, disabled, loading, error, empty.

## Keyboard / AT

## Tokens

Semantic roles only. No raw hex.

## Code

## SSR

No `window` at module scope. Theme via `getThemeInitScript()`.

## Migration

Replacement, codemod, and removal date if deprecated.
