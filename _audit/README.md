# `_audit/` — verification dev tools (not compiled)

Dev-only harnesses for **deep** verification (owner doctrine: whole-set checks, never surface spot-checks). Not part of the design system: not `@dsCard`-tagged, not compiled into `_ds_bundle.js`, no tokens exported. Open with a browser/preview; they iframe or mount real templates/components.

## Harnesses

- **`responsive-harness.html`** — the user-facing **Responsive preview**: manifest-driven, lists **every** template (grouped + filterable) and renders the selected one live at **390 / 768 / 1280 px** side by side. Media queries fire off the real iframe width, so it's a true device check. Fresh iframes per selection. Reach into the same-origin frames to read computed styles (e.g. confirm a 4-col grid collapses 4→2→1).

- **`responsive-overflow.html`** — whole-set horizontal-overflow gate: loads all 84 templates (manifest-driven) in **fresh single-navigation iframes** and fails if any has document-level horizontal overflow at mobile **390**. Canvas decks/social legitimately scroll *inside* `.cs-canvas-desk` (0 document overflow, flagged ◇). `window.__overflow.pass` must be `true`. **Method note:** reuse of one iframe across many `src` swaps races the `@import`ed `responsive.css` and produces false positives — always use a fresh iframe per template (single navigation).

- **`language-overflow.html`** — whole-set **language** gate (owner doctrine: language gets its own pass). Forces `Tiếng Việt` via `__dcSetProps` on **all 84** templates in fresh single-navigation iframes and fails on any VN-induced document horizontal overflow **or** text clipping (fixed-height / `nowrap` boxes) @390; also asserts VN actually applied on every template. `window.__language.pass` must be `true`. Verified 84/84 green.

- **`theme-overflow.html`** — whole-set **theme** gate. Forces dark via `__dcSetProps` on all 84 in fresh iframes. **Hard gate** (`window.__theme.pass`) = dark actually applies where a Theme tweak exists **+ 0 document horizontal overflow in dark** @390 **+ 0 reproducible solid-bg leaf-text WCAG fails outside `REVIEWED_OK`**. `parseColor` converts oklab/`color-mix` backgrounds via a 1×1 canvas so element-pack surfaces are not mistaken for the light `body` fallback. Allowlist = canvas decks whose accent-bright eyebrows on accent-strong sit ~4.22:1 (APCA-ok; do not retune packs for WCAG on 14px kickers). Light-only / print / VN instruments stay **n/a**. Companion proofs: `contrast-guard.html`, `apca-dark-preview.html`, `docs/contrast-report.md`.

- **`vn-overflow.html`** — loads every toggle-able template in sequence, forces **Tiếng Việt** via `window.__dcSetProps(rootName, {language:"Tiếng Việt"})`, and measures clipping / horizontal overflow (VN text is longer — the real risk is fixed-geometry deck slides and `nowrap` pills). Results collect on `window.__vn`. **Superseded as the whole-set gate by `language-overflow.html`** (all 84, fresh iframes, pass/fail); kept for its detailed per-element clip listing across the 44 toggle-able templates.

- **`a11y-harness.html`** — a11y CSSOM gate (in the fast runner, promoted from a manual-inspection page): coarse-pointer floors parsed from source per control's documented minimum, focus-visible proven by static scan (ancestor `:focus-within` pairing recognized as a valid ring), reduced-motion/high-contrast blocks present, every control named. `window.__a11ycss.pass` must be true. Companion to `a11y-gate.html` (keyboard/ARIA interaction — this one is static CSS).

- **`component-children-test.html`** — mounts the void-element components (TextField, Checkbox, Radio, Switch, SearchField, NumberField, Slider, Divider) **with a stray child** — the React #137 trigger — inside error boundaries. `window.__result.anyThrew` must be `false`. NOTE: it loads `_ds_bundle.js`, which the compiler regenerates only at end of turn, so re-run it on a **fresh** turn after editing component sources to see the current behavior.

- **`component-behavior-test.html`** — behavior smoke test beyond mount: **83** real interaction assertions covering every interactive public primary with a user-driven contract (overlays, forms, AI gates, shell chrome, media/copy); display-only primaries excluded by design. `window.__behavior.pass` must be `true`. Also loads `_ds_bundle.js`, so re-run on a **fresh** turn after editing component sources.

- **`token-contract.html`** — runtime contract test: applies each of the 15 element×variant scopes to a probe and asserts all 9 `--cs-accent-*` role tokens resolve non-empty (plus core text/semantic tokens). `window.__contract.pass` must be `true` (`elementFails === 0` and `coreMissing` empty). Complements the static tokens+base scan (element role-token completeness + no undefined no-fallback `var()`).

- **`docs-consistency.html`** — reads `_ds_manifest.json` + `VERSION` and asserts every count claim in live prose (README / SKILL / llms) matches the compiler, plus audit prose card-count claims (`_audit/index.html` / this README / namespace-portability) match `manifest.cards`. Also asserts `VERSION` is semver and `package.json` matches it (auto-bumps on main), that live entrance docs do not reintroduce `CHANGELOG.md`, that the **stale-phrase blacklist** (retired suite/pack counts plus three-axis leftovers) stays out of README / SKILL / llms + `docs/*.md`, that the generated root `DESIGN.md` exists with front-matter version = `VERSION`, and that **doctrine matches source** (10 accent roles incl. `on-strong`, full depth scale, default lang `vi`, breakpoint CSS↔JSON, `base/` depth fallbacks). Historical audit notes under `_audit/archive/` are not scanned. Node twin: `_audit/ci/test-docs-consistency.mjs`. `window.__docs.pass` must be `true`. Run after any count-touching change.

- **`asset-weight-budget.html`** — regression ceilings for `assets/aurora-{hoa,thuy,moc,kim}.webp` (≤300 KB each, ≤1.2 MB set, FIND-016). Fails on growth / missing / unexpected aurora WebP or legacy aurora PNG. `window.__assetweight.pass` must be `true`.

- **`docs-lang-parity.html`** — every operator-facing EN `docs/*.md` has a `docs/vi/` counterpart; VI is not an empty/TODO stub (≥40% of EN length); stale-phrase blacklist applies to both EN and VI. Historical audit notes under `_audit/archive/` are not tracked. Does not duplicate component/template bilingual systems. `window.__docslangparity.pass` must be `true`.

- **`namespace-portability.html`** — fetches every manifest-indexed source (84 template `entryPath`s + 57 card `path`s) plus the bundle-consuming UI-kit pages, and **fails if any hardcodes the compiler's project-id namespace suffix** (`CyberSkillDesignSystem_<6-hex>`, e.g. `…_847b3c`). That suffix is derived from the project id and changes on import into another project, so sources must resolve it by prefix (`window[Object.keys(window).find(k=>/^CyberSkillDesignSystem_[0-9a-f]{6}$/.test(k))]`) or read the `window.CyberSkillDS` alias that `ds-base.js` publishes. Also asserts the alias + the template mount pattern are actually present (not just the bad pattern absent). `window.__nsguard.pass` must be `true`. Keeps the system **zero-touch on re-import** — run after adding any card, template, or bundle-consuming page.

- **`visual-diff.html`** — visual-regression **review assist** + advisory runner row (drift judged by eye — this environment can't rasterize nested-iframe content; the `baselines/` refs are 909×540). Compares a live template render against its stored baseline side-by-side or as a `mix-blend-mode:difference` overlay; drift is judged by eye. Manifest-driven coverage list; 15 curated baselines anchor high-traffic product/document/deck shells, not every template. Regenerate a baseline after an intentional redesign.

- **`component-visual-diff.html`** — component-tier counterpart to `visual-diff.html`: 12 curated components (Button, Badge, Alert, Toast, Card, DataTable, Accordion, TextField, Avatar, ProgressBar, Switch, Tooltip) rendered **directly** (no nested iframe — sidesteps the html-to-image limitation entirely) against stored 280×160 crops in `baselines/components/`. Advisory runner row checks baseline-file freshness only; drift judged by eye. Exemplars across the atomic tiers, not exhaustive — `guidelines/atomic-view.html` is the full live story set.

- **`contrast-guard.html`** — deterministic dark-contrast safety (token + static CSS; complements the theme-overflow DOM hard gate). (1) **Static source lint**: any base rule setting `color: var(--cs-color-brand-umber)` on a *themeable* surface (surface-*/transparent, or a `color-mix` that includes one) without a matching `[data-theme="dark"]` override **fails** — the nav-item/secondary-button class the user hit. (2) **Token-pair matrix**: every semantic text×surface pairing scored (WCAG) in **light + dark** from `tokens/tokens.json` — no DOM, so no false reads. (3) Screen-template inline umber-in-header is **advisory** (bg unknowable statically). `window.__contrastguard.pass` must be true. Run after touching `base/*.css` or `tokens/`.

- **`story-coverage.html`** — guards `guidelines/atomic-view.html`: every primary export has a story **and** every tweakable primary in `PLAYGROUND_REQUIRED` appears in a live `controls` + `renderC` playground (not specimen-only). Sub-parts excluded. Loads `_ds_bundle.js` (re-run on a fresh turn). `window.__storycov.pass` must be true.

- **`bilingual-parity.html`** — v3 bilingual-doctrine gate: reads the central registry `components/_i18n/strings.js` and **fails** if any component lacks an `en`/`vi` table, has mismatched key sets across locales, or any empty value. Keeps EN·VI in lockstep as Batch 1 wires components. `window.__bilingual.pass` must be true.

- **`run.html`** — one-click **gate runner**: loads every fast deterministic gate in sequence in fresh iframes, reads each verdict global, and shows a pass/fail board + aggregate `window.__run.pass`. **Row lifecycle:** each gate starts **pending**, only the active gate shows **running**, then **pass/fail/timeout** (advisory rows stay labeled). The three whole-set state audits (`responsive-overflow`, `language-overflow`, `theme-overflow` — ~5 min each) stay on the index, run them separately.

- **`apca-dark-preview.html`** — dark-pack APCA page: since v4.0.0 a **fast-runner gate** (all 15 dark elemental packs must hold bright ≥ 75 · accent ≥ 60 · button ink ≥ 75 · ink ≥ 75; `__apcaPreview.pass` / `currentFail === 0`); still previews derived proposals for future packs.

- **`element-geometry.html`** — Element colour geometry hard gate: soft / middle / deep intensity sync across five elements, variant distinctness, light↔dark hue identity, Thổ middle pinned to logo ochre, packs generated from `tokens/element-seeds.json`. `window.__elementgeometry.pass` must be true. Regenerate packs with `npm run tokens:elements`.

- **`style-contract.html`** — **hard** Style axis allowlist: sole pack `liquid-glass` (absent ≡ default); asserts `tokens/styles.css` import + `--cs-style-pack`. `window.__stylecontract.pass` must be true.
- **`template-schema-test.html`** \u2014 template content-schema v2 gate (in the fast runner): validates every opt-in `templates/<slug>/content-schema.json` sidecar against the JSON Schema (`templates/schema/content-schema.schema.json`) and bidirectionally against the template's real `{{ hole }}`s. It also **gates coverage**: every template exposing an authorable content hole must ship a sidecar, where axis/control-flow holes (`rootTheme`, `langAttr`, `elAttr`, `vaAttr`, `dirAttr`, `true`, `false`, `is*`, numeric literals), boolean tweak holes (`show*`, `hide*`, `has*`, `enable*`, `with*`), and runtime-control holes (`tabs`/`tab`/`lens`/`chatOpen`/`closeChat`, `set*`/`open*` handlers) are excluded by doctrine. `window.__schemav2.pass` must be true; the gate prints the live split (eligible / axis-only / total) rather than a hardcoded count.

- **`esm-smoke-test.html`** — ESM-path gate (in the fast runner): `_esm/cs.mjs` imports (self-ensures React + bundle, prefix-resolved namespace), export list in lockstep with `_ds_manifest.json` (drift guard both directions), Button mounts with brand tokens. `window.__esm.pass` must be true.

- **`token-pipeline-test.html`** — native token parity gate (in the fast runner): re-derives every expected Swift/Kotlin/Dart constant from `tokens.dtcg.json` (rem→px@16, em→`…Em`, rgba→ARGB) and asserts verbatim presence in `tokens/native/`, plus `tokens/provenance.json` integrity (source/target sha-256 pinning is the drift authority — the release stamp is informational, since natives regenerate on *token* change, not on every version bump; counts, zero skipped). `window.__tokenpipe.pass` must be true.

- **`token-format-parity.html`** — cross-format token parity gate (in the fast runner, Jul 2026 hardening): every `--cs-*` declaration in `tokens/*.css` equals its mirror in `tokens.json`, `tokens.js` (live ESM import, deep-equal vs the JSON), and DTCG (via `$extensions["com.cyberskill"].css` else the typed transform) — base `:root` + dark/system themes + 15 element packs + 15 dark packs; plus the manifest's 4 duration values equal `motion.css` (the reduced-motion 0ms compiler-bug guard). `window.__tokenformat.pass` must be true. Run after any token change.

- **`font-face-integrity.html`** — type-layer gate (fast runner): every `@font-face` in `tokens/fonts.css` is self-hosted under `fonts/` (relative `../fonts/*.woff2`, no CDN), subset-split with `font-display: swap`, and resolves to bytes that start with the `wOF2` magic; every family a `--cs-font-family-*` token names first has faces here **including the Vietnamese subset** (`U+1EA0-1EF9` — the brand anchor), and no self-hosted family is nameless; `_ds_manifest.json` `fonts[]` matches the parsed faces entry-for-entry and `brandFonts[]` matches the token-named family set; every family loads for real through `document.fonts`; and `.cs-display-face` retargets `--cs-heading-family` to `--cs-font-family-display` without leaking onto body copy. `window.__fontface.pass` must be true. Run after any change to `tokens/fonts.css`, `fonts/`, or a family token.

- **`dtcg-typing.html`** — DTCG structural gate (fast runner): every `$value` leaf carries a W3C `$type`, every `{alias}` resolves (chains, no cycles), every shadow is a structured object/array with full layer fields (raw CSS strings live only in the extension), byType counts equal provenance. `window.__dtcgtyping.pass` must be true.

- **`version-stamp.html`** — every stamp equals `VERSION` (auto-bumps on main): `package.json`, `tokens.json`/`tokens.js` metas, DTCG `$extensions`, `provenance.json` release + dtcgStamp, and `DESIGN.md` front matter. `window.__versionstamp.pass` must be true.

- **`support-runtime-identity.html`** — fetches all 84 `templates/*/support.js`, sha-256s each (SubtleCrypto), asserts exactly **one** unique hash + copy count == manifest template count (the DC runtime is byte-identical per compiler contract — a second hash means a hand edit or stale copy). `window.__supportid.pass` must be true.

- **`package-exports-integrity.html`** — packaging gate: every `package.json` `files`/`module`/`types`/`style`/`exports` target exists, every entry-point target is pack-covered by `files`, dual ESM entries (`_esm/react.mjs` default + `_esm/cs.mjs` legacy) are ESM-shaped, and their re-exports ⊆ the bundle header's exposed exports. `window.__pkgexports.pass` must be true.

- **`test-subtree-consume.mjs`** (Node unit, `npm run test:subtree-consume`) — copies the portable subset (`styles.css` + `base/` + `tokens/` + `fonts/` + `_esm/` + `_ds_bundle.js`) to a temp tree and Playwright-proves tokens/fonts + ESM Button mount without the full clone — the Stitch/Claude subtree-copy path the in-repo consumer-smoke does not cover.

- **`template-lang-parity.html`** — bilingual-source gate over all 84 `.dc.html`: en/vi hole-map key parity (21 map templates), `sc-if` `isEN`/`isVN` branch pairing (24), every `language`-tweak template has a mechanism, and an EN-leak lexicon (email chrome · Skip to content · Statement of work · Performance improvement plan · Change note · …) must not appear outside `isEN` guards / the `en` map. `<title>` and HTML comments (including `@template name`) are masked as catalog chrome (FIND-125). The 40 VN-first stacked instruments are leak-exempt **by design** (both languages always render — no hidden-language mode). `window.__langparity.pass` must be true.

- **`design-md-parity.html`** — rebuilds the root `DESIGN.md` in-browser via the same `scripts/design-md-lib.mjs` the generator uses (DTCG + manifest + `VERSION` inputs) and asserts **byte equality** plus per-token row matches. Manual edits and stale regenerations fail; fix with `npm run build:design-md`. `window.__designmd.pass` must be true.

- **`bundle-freshness.html`** — browser replication of `ci/check-bundle-freshness.mjs`: re-hashes every source recorded in the `_ds_bundle.js` header and asserts header equality + manifest component sources ⊆ header. The Node script remains the CI authority (it also discovers **new** files by walking the tree). `window.__bundlefresh.pass` must be true.

- **`a11y-gate.html`** — a11y interaction gate (in the fast runner): Dialog/Drawer/AlertDialog focus management (initial focus · Tab trap · restore-on-close · Escape), roving tabindex (Tabs · SegmentedControl · Menubar), combobox `aria-activedescendant`, role/label contracts (Rating · InputOTP · DataGrid `aria-sort` · Carousel · Popconfirm · live regions), plus open-state keyboard/focus for Cascader · TreeSelect · Tour · HoverCard · ContextMenu (pairs with axe force-open surfaces). `window.__a11y.pass` must be true; loads the bundle — re-run on a fresh turn.

- **`light-contrast.html`** — **hard** light-mode DOM contrast walk (mirrors `theme-overflow`): leaf text over solid backgrounds must meet WCAG AA @1280. `window.__lightcontrast.pass`.

- **`no-third-party.html`** — **hard** product-surface origin gate: templates · kits · Atomic View must not load scripts from CDN; React + Babel vendored under `_vendor/`. `window.__nothirdparty.pass`.

- **`axe-smoke.html`** — **hard** axe-core 4.10.0 gate (vendored at `_audit/vendor/axe.min.js`, no CDN): mounts every public primary via `_audit/lib/axe-fixtures.js` (bilingual EN·VI; Cascader / TreeSelect / Menubar / Combobox expanded before the scan) and fails on any serious/critical WCAG 2 A/AA violation (Storybook a11y enforcement without a separate test-runner). Inventory lock: `_audit/ci/test-axe-coverage.mjs`. `window.__axesmoke.pass` must be true.

## Forcing states for verification (from a frame's own context)
- **Language:** `win.__dcSetProps(win.__dcRootName(), { language: "Tiếng Việt" })`

- **Theme:** `win.__dcSetProps(win.__dcRootName(), { theme: "dark" })` (the DC binds `data-theme`; a `postMessage` is overridden by the prop)
- **Any prop:** `win.__dcSetProps(win.__dcRootName(), { element: "Hỏa · ember" })`

Note: these force a live re-render — a good way to catch reconcile bugs (a `TextField` given a value as **children** crashes with React #137 on re-render; pass `default-value`, and see the void-element API rule in `docs/conventions.md`).
Screenshots of iframe-based harness pages don't capture nested-iframe content (html-to-image limitation) — verify by reaching into `iframe.contentDocument`, or load a single template directly and screenshot that.
