# Decision title

Status: proposed (an option or recommendation is not acceptance).
Owner: pending explicit assignment.

## Decision and evidence

State the affected behavior, verified facts, assumptions and source revision.

## Options and recommendation

Describe trade-offs and recommend one option using the evidence.

## Authorized outcome

Record the explicit decision, decision-maker, date and scope. Keep production,
push, deployment, merge and human acceptance authorization distinct.

## Validation and consequences

Name affected contracts, migration requirements and checks. Link retained results;
never promote an unexecuted plan or an empty acceptance row to a pass.
