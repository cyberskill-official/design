# Quyền thực thi script chính xác cho đầu ra Vercel tĩnh

Thẩm quyền tác giả là `scripts/site-deployment-policy.json`. Sau khi tập hợp Storybook và allowlist công khai, `scripts/vercel-static-output.mjs` phân tích từng HTML cuối và ghi hash HTML chính xác, hash script thực thi cùng chính sách phản hồi trong `public-site-csp.json`. Manifest tuân theo `scripts/site-csp-manifest.schema.json`. Định danh nguồn của nó là bằng chứng suy ra, không phải phê duyệt bảo mật hay bằng chứng triển khai.

`scripts/lib/site-csp.mjs` dùng parse5 để phân tích văn bản script đã chuẩn hóa theo trình duyệt. Khối dữ liệu JSON và nguồn `text/x-dc` inert không được cấp quyền thực thi. Nguồn DC được runtime hiện có diễn giải; runtime tạo script bằng producer định kiểu dùng chung `scripts/template-runtime/dc-logic-source.mjs`. Builder băm đúng wrapper đó, gồm token component xác định. `scripts/build-template-primitives.mjs --check` kiểm tra producer được chiếu và mọi bản sao runtime template đều mới. Event native của template dùng binding `data-cs-on-*` được diễn giải thành React listener; form preview trạng thái native đăng ký listener submit. Thuộc tính handler native và URL JavaScript không biết làm site build thất bại.

Card `text/babel` và trang kit đã phân loại chỉ được biên dịch trong đầu ra site cuối bằng runtime Babel cục bộ đã pin, khớp preset và plugin react/env mặc định của nó. HTML/JSX nguồn không đổi. Thuộc tính lạ, preset tùy chỉnh, nguồn khác origin/chưa phân loại hoặc cách dùng API Babel riêng đều bị từ chối. Loader transpiler không còn cần thiết chỉ được bỏ khỏi các trang đã chuyển đổi đó; byte script thông thường cuối nhận hash chính xác.

Cấu hình Vercel Build Output API được sinh chứa route HTML chính xác với hash riêng, alias index cùng chính sách và phương án dự phòng nghiêm ngặt không cho inline. Redirect cũ hiện có chạy trước. Chỉ index thư mục được sinh nhận redirect `/directory` sang `/directory/`, giữ điều hướng asset tương đối; đường dẫn không liên quan giữ hành vi hiện có. Query string không đổi chính sách được chọn. Redirect dùng header `Location` cùng status theo tài liệu Build Output API. Giữ query là hợp đồng adapter cục bộ và vẫn phải kiểm tra header thật sau triển khai Vercel được cho phép; kiểm thử này không chứng nhận định tuyến của nền tảng. Bộ phân giải route hữu hạn cục bộ chạy tập cấu hình được sinh này trong kiểm thử; nó không phải trình giả lập Vercel đầy đủ hay bằng chứng nền tảng đã triển khai.

Chính sách script cho phép tệp cùng origin và hash script chính xác. Không cấp `unsafe-inline`, `unsafe-eval`, nonce tĩnh tự đặt, `unsafe-hashes` hay origin script CDN. Điều khiển style, image, font, connection, frame, worker, base và form hiện có vẫn nguyên. Cụ thể, CSS inline vẫn được cho phép vì component và Storybook hiện dùng style inline. Thay đổi này siết script, không phải mọi cơ chế inline. Ranh giới nội dung hạn chế riêng của Editor không đổi.

Giới hạn CSP 4 KiB mỗi phản hồi là ngân sách dự án, không khẳng định giới hạn header phản hồi của nền tảng. Generator còn kiểm tra ngân sách hiện tại 2.048 route. Cả hai đều thất bại khi không hợp lệ. Build lại sau khi đổi HTML, serializer dùng chung, chính sách site hoặc đầu vào Storybook; không sao chép hash từ release cũ hay cấp quyền cho script runtime đang bị chặn chỉ để vượt kiểm thử.

Kiểm chứng cục bộ bắt buộc: `node _audit/ci/test-site-csp.mjs`, một lượt `npm run build:site` mới, rồi `node _audit/ci/test-site-csp-browser.mjs` cùng kiểm tra trình duyệt public-site hiện có. Kiểm tra CSP trình duyệt xác minh mọi hash HTML và alias đã xuất, manager/story/docs Storybook thật, Markdown song ngữ, toàn bộ 85 template đã build, event/form native được diễn giải và việc chặn script/handler native không biết trong Chromium, Firefox, WebKit. Biên nhận build và browser chỉ chứng minh byte cục bộ được kiểm thử.

Tệp `_headers` gốc vẫn là chính sách tương thích cũ cho host hỗ trợ nó. Nó không biểu diễn hash script theo từng HTML đầu ra và không phải chính sách Vercel đã siết. Host khác cần adapter tường minh giữ chính sách của từng route HTML và alias, cùng kiểm thử dương/âm như trên. Máy chủ thuần phục vụ `.vercel-static/` không tự áp dụng manifest. Phát hành và triển khai cần cho phép riêng; sau triển khai được cho phép, kiểm tra header thật, redirect và chức năng trước khi khẳng định nghiệm thu nền tảng.
