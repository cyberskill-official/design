# Progressive viewport and spacing changes

Dialog and AlertDialog retain their original `vh` fallback declarations. A feature query adds dynamic viewport height and physical safe-area edge bounds, preserves internal scrolling, and leaves ordinary zero-inset geometry unchanged. Physical left/right insets represent device edges regardless of text direction. The three-engine test compares both dialog variants, LTR/RTL and four viewports, a live viewport resize, a negative feature-query control and synthetic nonzero insets. Synthetic values test the arithmetic; they do not establish physical iOS browser-toolbar, keyboard or notch acceptance. Consumers still own their viewport configuration, including `viewport-fit` when appropriate. See [CSS environment variables](https://www.w3.org/TR/css-env-1/) and [dynamic viewport units](https://www.w3.org/TR/css-values-4/#viewport-relative-lengths).

Three standalone collection hover paint rules now require `(hover: hover)`. Selection, native focus, keyboard behavior and disabled semantics remain independent. Tests use actual fine/coarse media queries and pointer interaction; they preserve the keyboard-focus target in both contexts.

Five additional collection declarations use existing `--cs-space-3` or `--cs-space-5` values: ListItem gap and inline padding, Item block padding, Timeline trailing spacing and Accordion trigger gap. Their numeric values remain 12px and 20px at both densities. Four actual component exports are measured across 24 theme/direction/density scopes, three engines and fine/coarse pointers, with both source and whitespace-minified leaf CSS. Token interventions verify consumption while retained 14px Item inline padding remains unchanged. This is exact role adoption, not an expansion of compact-density behavior.

`test-progressive-viewport-browser.mjs` and `test-collection-spacing-browser.mjs` write source-bound receipts under `test-results/`. Existing print CSS remains in `base/glass.css`. Fluid typography and additional density scales require authored design choices; these changes introduce neither.
