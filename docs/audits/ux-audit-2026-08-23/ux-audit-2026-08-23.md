## 2. Layer-by-layer audit

### Tokens & color

- **Primitive → semantic → component** three-layer architecture intact (`tokens/*.css` → JSON/ESM/DTCG/native).
- **10 accent roles** including `--cs-accent-on-strong` present in all 15 element×variant packs; light-contrast gate **0 failures** across 85 templates.
- **Depth scale** (`--cs-depth-nav` 50 … `--cs-depth-toast` 200) matches `tokens/elevation.css` and dialog/toast behavior.
- **New:** `--cs-scroll-padding-block-*` aliases in `tokens/spacing.css` for WCAG 2.2 focus-not-obscured scroll offsets.

### Typography

- UI: Be Vietnam Pro; display: Space Grotesk; mono: JetBrains Mono — self-hosted WOFF2.
- Heading `text-wrap: balance`; body `text-wrap: pretty` in reset.
- `--cs-prose-measure: 45rem` for long-form kit copy.
- Ramp aligned to token scale; no off-ramp px literals in base components.

### Spacing & grid

- 4px base grid (`--cs-space-1` … `--cs-space-24`); section floor 64px / ceiling 96px.
- Breakpoints tokenized; `phone` at 360px; 320 reflow rules in `base/responsive.css` §10.
- Container max 1320px; CQ compatibility layer (`.cs-cq`) for opt-in hosts.

### Components & states

- 106 JSX primaries with `.d.ts`, `.prompt.md`, Figma stubs.
- Interaction states: hover/active/disabled/loading on Button, fields, toggles; reduced-motion respected.
- Carousel dots: 9px visual + `::before` hit-area expansion to ≥24px (WCAG 2.5.8).
- Nested `outline: none` on inner inputs (search, taginput, editor) — acceptable when parent control carries focus ring.

### SVG iconography

- `Icon` component + 28-name registry; Phosphor-style SVG paths — no emoji structural icons.
- DataGrid pin uses registry strings (FIND-125 closed).

### Light / dark / system

- `[data-theme="dark"]` and `[data-theme="system"]` packs with `prefers-color-scheme` mirrors in controls.
- Theme-overflow and light-contrast gates green for all templates.

### Accessibility

- Focus: composite `:focus-visible` ring global; skip links on app-shell, dashboard, auth, article, marketing-page, kits.
- **New:** shared `.cs-skip` focus-visible treatment in `base/reset.css`.
- Touch targets: ≥44px on coarse pointer for buttons; nav items grown at ≤768px.
- Gaps: AT matrix rows still human-only (see `docs/audits/at-operator-handoff-2026-08-09.md`). Product shells + print sheets expose main landmarks (UX-032).

### Implementation consistency

- **Bug found & fixed:** `audit-probe-suite.mjs` waited for `window.__langoverflow` but gate publishes `window.__language` — caused false TIMEOUT; CI workflow was already correct.
- Status hub: shared `cs-tokens.css` on regen (UX-034); page-local status roles tokenized to CDS vars (UX-035).
- Kits use shared `.cs-skip` (UX-031); CQ hosts on website/status-hub wrappers (G1 partial).
