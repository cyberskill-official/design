---
title: Migrating from 2.x
description: Move an app from the Umber & Ochre system (2.x) to Ink & Gold (3.0).
---

3.0 is a new major version: new tokens, React components on Base UI, and a much smaller package. 2.x stays on npm under the `legacy` tag and on the repository's `legacy` branch, so nothing moves until you upgrade.

## Staying on 2.x for now

Pin 2.x from npm. The caret keeps every later 2.x release and never jumps to 3.0:

```json
"@cyberskill/design": "^2.8.0"
```

Apps that installed straight from GitHub (`github:cyberskill-official/design` or the old `design-system` name) must move to npm. Since 3.0 the repository root is a workspace, not a package, so a GitHub install no longer gives you a working package. If the app's lockfile points at an older commit, pin that exact commit to keep the code it builds with today; finance, for example, is on `3edeb1350c2e48761bee18f7c10c323e6103ff7d`, a 1.0-era build, so moving it to the latest 2.x is itself an upgrade to test:

```json
"@cyberskill/design": "github:cyberskill-official/design#3edeb1350c2e48761bee18f7c10c323e6103ff7d"
```

## Steps

1. **Install 3.x** and import the styles (see [Get started](/docs/get-started)). Load the fonts yourself: 3.0 ships no font files (2.x self-hosted them).
2. **Swap tokens** with the tables below, then delete the app's own copies of those values.
3. **Move the app in one go, or route by route.** 2.x and 3.0 share about 50 class names (`.cs-button`, `.cs-dialog`, `.cs-card`, `.cs-field`, `.cs-table`…), so a page that loads both stylesheets restyles each version's components with the other's CSS. Either switch the whole app at once, or keep each route on one stylesheet. To keep 2.x code during the move, install it under an alias: `"cs2": "npm:@cyberskill/design@^2.8.0"`.
4. **Rename components** with the table below.
5. **Check focus and layers**: the focus ring and z-index scale changed (see below).
6. **Run your accessibility checks** in light and dark.

## Token names

3.0 drops the `--cs-` prefix. Names follow the Practice app (shadcn-style), so a Tailwind app maps them with one import.

| 2.x | 3.0 |
|---|---|
| `--cs-color-surface-page` | `--background` |
| `--cs-color-surface-panel` | `--panel` (`--card`, `--popover` are aliases) |
| `--cs-color-surface-raised` | `--raised` |
| `--cs-color-text-primary` | `--foreground` |
| `--cs-color-text-muted` | `--muted` |
| `--cs-color-text-inverse` | `--primary-foreground` |
| `--cs-color-text-accent` | `--accent-text` (gold that passes 4.5:1 as text) |
| `--cs-color-border-default` | `--border` |
| `--cs-color-brand-umber` | `--primary` (Ink) |
| `--cs-color-brand-ochre`, `--cs-color-accent-ochre` | `--accent` (Gold); `--gold` is an alias |
| `--cs-color-link`, `--cs-color-link-hover` | Use the `Link` component (it uses `--primary`) |
| `--cs-color-semantic-success \| warning \| danger \| info` | `--success`, `--warning`, `--destructive`, `--info` |
| `--cs-color-semantic-*-fg` | `--success-foreground` etc. (text on the filled color) |
| `--cs-color-semantic-*-text` | The status token itself: every status color passes 4.5:1 as text |
| `--cs-doc-*` | Removed (documents moved out of the design system) |

## Practice: names that look the same but mean something else

| Token | Practice today | 3.0 |
|---|---|---|
| `--accent` | Soft cream hover tint | **Gold**, for one key action per view. Move hover tints to `--raised` or `--primary-soft` |
| `--input` | Input background (white) | Input **border** color. Input backgrounds use `--panel` |
| `--ring` | Translucent gold glow | Solid `--primary`, drawn as a 2px outline with a 2px offset |
| `--focus-ring` | Umber outline | Removed: use `--ring` |
| `--z-*` | `--z-modal: 60`, `--z-toast: 70`… | `--z-sticky` 1100, `--z-overlay` 1200, `--z-modal` 1300, `--z-dropdown` 1400, `--z-toast` 1500, `--z-tooltip` 1600. Keep app layers below 1100 |
| `--space-sm`, `--space-md`… | Named steps | Numbered 4px steps: `--space-1` (4px) to `--space-20` (80px) |
| `--medal-*`, `--brain-*`, `--glass-*`, `--hero-glow-*` | App tokens | Not in the system: keep them in the app, defined from 3.0 tokens |

## Look and feel

| 2.x | 3.0 |
|---|---|
| Umber `#45210E` + Ochre `#F4BA17` on warm cream | Ink `#14243D` + Gold `#F4BA17` on cool gray `#F7F8FA` |
| Be Vietnam Pro everywhere, Space Grotesk display | Manrope headings, Be Vietnam Pro body, JetBrains Mono data |
| Gold focus glow | Ink outline in light, near-white in dark |

## Imports

| 2.x | 3.0 |
|---|---|
| `@cyberskill/design`, `/styles.css`, `/tokens.css` | Same paths, new contents |
| `/assets/*` | New file names (see Assets below) |
| `/react`, `/legacy`, `/components/*`, `/source`, `/base/*`, `/styles/components/*` | `@cyberskill/design` (every component, flat named imports) |
| `/tokens/*`, `/schemas/*` | `@cyberskill/design/tokens` (typed object) or `/tokens.json` |
| `/styles.min.css`, `/styles.layered.css`, `/dist/styles.css` | `@cyberskill/design/styles.css` (already in cascade layers) |
| `/_ds_bundle.js`, `/_ds_manifest.json` | Removed |
| – | New: `/charts`, `/table`, `/forms`, `/date`, `/utils`, `/tailwind.css` |
| Docx export, native tokens, templates | Not in 3.0; still on `legacy` |

## Components

Renamed in 3.0:

| 2.x | 3.0 |
|---|---|
| `Breadcrumb` | `Breadcrumbs` |
| `Divider` | `Separator` |
| `ProgressBar` | `Progress` (or `Meter` for a value in a range) |
| `InputOTP` | `OtpField` |
| `HoverCard` | `PreviewCard` |
| `Steps` | `Stepper` |
| `Sidebar`, `NavItem` | `SideNav`, `SideNavGroup`, `SideNavItem` |
| `CommandPalette` | `CommandMenu`, `CommandGroup`, `CommandItem` |
| `Toast`, `ToastStack` | `ToastProvider` once near the root, then `useToast()` |
| `Tab` | `Tabs`, `TabsList`, `TabsTab`, `TabsPanel` |
| `CardBody` | `CardContent` (with `CardHeader`, `CardTitle`, `CardDescription`, `CardFooter`) |
| `NativeSelect` | `Select` |
| `Popconfirm` | `AlertDialog` |
| `Result` | `EmptyState` |
| `StatusIndicator` | `Badge` with a status `tone` |
| `Chart` | `BarChart`, `LineChart`, `AreaChart`, `DonutChart`, `Sparkline` from `@cyberskill/design/charts` |
| `DataGrid` | `DataTable` from `@cyberskill/design/table` |
| `FormFieldArray`, `FormWizard` | `FormField` from `@cyberskill/design/forms`, with `Stepper` for steps |
| `Icon`, `CS_ICONS` | Phosphor icons from `@phosphor-icons/react` |
| `Logo`, `CS_LOGO_*` | The SVG files under Assets below |
| `Editor`, `EDITOR_SCHEMA` | `@cyberskill/cyber-editor` |
| `LocaleProvider`, `OverlayProvider` | Not needed: pass labels as props; `ThemeScope` themes portals |

Not in 3.0 (still on 2.x): the AI set (`AIDisclosureBadge`, `ChatMessage`, `CitationList`, `ConfidenceMeter`, `HumanReviewGate`, `LumiAvatar`, `PromptInput`, `PromptSuggestions`, `TypingIndicator`; see the [AI assistant pattern](/docs/patterns/ai-assistant) for building one), `Anchor`, `AspectRatio`, `BackTop`, `Carousel`, `Cascader`, `ColorPicker`, `Comment`, `DescriptionList`, `Dock`, `FloatingActionButton`, `HotKeys`, `Image`, `InlineEdit`, `InputGroup`, `Item`, `List`, `ListItem`, `Masonry`, `Mentions`, `QRCode`, `Rating`, `Sortable` (use dnd-kit in the app), `Splitter`, `TagInput`, `Terminal`, `Timeline`, `Tour`, `Transfer`, `Tree`, `TreeSelect`, `TreeTable`, `Watermark`.
