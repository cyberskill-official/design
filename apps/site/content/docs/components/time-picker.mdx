`TimePicker` is a text field for a time of day with a list of suggested times. Typing is the fast path and accepts `9:30`, `09.30`, `930`, `21:30`, `9:30 PM`, and the Vietnamese forms `9h30`, `9h`, `21h`, `9 h 30`, `9g30`, `9g` and `SA`/`CH`. The list steps every 15 minutes by default and opens on the current time. For a date and a time together, use `DateTimePicker` from [Date picker](/docs/components/date-picker).

```tsx
import { TimePicker } from '@cyberskill/design/date';
```

The value is always 24-hour `"HH:mm"` (or `null`), whatever the field shows. A typed time between steps, such as `9:37`, is kept. Text that is not a time inside `min`/`max` stays in the field with `invalidMessage`, and `onValueChange` gets `null` so a form does not keep the previous time. `min` and `max` take the same forms as typing (`"9:00"`, `"9h"`) and are compared as times.

Pass `name` to submit `HH:mm` with a plain form, and `onBlur` / `inputRef` for React Hook Form (see [Forms](/docs/components/forms)).

## Accessibility

- A Base UI combobox: the input has the visible label and the list is a listbox of options. Help and error text are linked to the input; an invalid time sets `aria-invalid`.
- ↓ or a click opens the list with the current time highlighted and in view. ↑/↓ move, Enter picks, Escape closes. Typing narrows the list ("14" shows 14:00 to 14:45).
- The current time is marked by a check and bold weight. List rows grow to 44px on touch screens.
