---
title: Components
description: Accessible React components built on Base UI and styled with Ink & Gold tokens.
---

Every component works with keyboard and screen readers, is tested with axe in light and dark, and accepts `className` for local tweaks. Pick a component from the sidebar.

| Group | Components |
|---|---|
| Actions | Button, Icon button, Button group, Link |
| Forms | Text field, Textarea, Select, Checkbox, Radio group, Switch, Segmented control |
| Display | Badge, Status, Tag, Avatar, Card, Stat, Table |
| Feedback | Alert, Toast, Progress, Skeleton, Empty state |
| Overlays | Dialog, Menu, Tooltip, Popover |
| Navigation | Tabs, Breadcrumbs, Pagination, Stepper, Side navigation |
| Data | Chart presets, Data table |
