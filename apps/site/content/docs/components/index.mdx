---
title: Components
description: Accessible React components built on Base UI and styled with Ink & Gold tokens.
---

Every component works with keyboard and screen readers, is tested with axe in light and dark, and accepts `className` for local tweaks. Pick one from the sidebar or the table below.

| Group | Components |
|---|---|
| Actions | Button, Icon button, Button group, Toggle, Link, Copy button |
| Text input | Text field, Password field, Textarea, Number field, OTP field, Tag input, File upload, Avatar upload |
| Choice | Select, Combobox, Autocomplete, Multi-select, Checkbox, Radio group, Switch, Segmented control, Slider |
| Date and time | Calendar, Date picker, Date range picker, Date and time picker, Time picker (`@cyberskill/design/date`) |
| Forms | Form, Fieldset, React Hook Form helpers (`@cyberskill/design/forms`) |
| Display | Badge, Tag, Avatar, Card, Stat, Table, Kbd, Code block, Prose |
| Feedback | Alert, Toast, Progress, Meter, Spinner, Skeleton, Empty state |
| Overlays | Dialog, Alert dialog, Drawer, Popover, Tooltip, Preview card, Menu, Context menu, Command menu |
| Navigation | Tabs, Breadcrumbs, Pagination, Stepper, Side navigation, Navigation menu, Menubar, Toolbar |
| Layout | Accordion, Collapsible, Separator, Scroll area |
| Data | Chart presets (`@cyberskill/design/charts`), Data table (`@cyberskill/design/table`) |

**Not in 3.0:** carousel, tree and tree select, cascader, transfer list, color picker, rating, timeline, tour, splitter, drag-and-drop sorting (use dnd-kit in the app) and rich text editing (use `@cyberskill/cyber-editor`). Ask in the repository if a product needs one.

Behavior for every interactive component comes from [Base UI](https://base-ui.com), so focus management, keyboard support and ARIA follow the WAI-ARIA patterns without custom code.
