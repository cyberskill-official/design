`@cyberskill/design` includes an `ai/` folder written for AI coding tools. It is generated from this site and from the package's type definitions on every build, so it always matches the code.

| File | What it gives an AI |
|---|---|
| `ai/INDEX.md` | Setup, the rules, and every component with its import and doc file. One small file to read first. |
| `ai/components/<name>.md` | One component: when to use it, examples, props, exact TypeScript types, accessibility. Read only the ones needed. |
| `ai/motion.md` | The motion rules: which `--motion-*` recipe for what, reduced motion, the `/motion` entry. Read before adding any animation. |
| `ai/color.md` | The color rules: color roles and `data-tone`, what gold means, category tones. Read before choosing any color. |
| `ai/tokens.md` | Every token with light and dark values and its Tailwind name, the color roles and the motion recipes. |
| `ai/SKILL.md` | A Claude Code skill that points the agent at the files above. |
| `ai/cursor-rule.mdc` | The same guidance as a Cursor rule. |

## Install it in your app

```bash
npx @cyberskill/design ai-setup
```

This writes `.claude/skills/cyberskill-design/SKILL.md`, `.cursor/rules/cyberskill-design.mdc` and a marked section in `AGENTS.md` (other content in `AGENTS.md` is left alone). Run it again after upgrading the package; use `--dry-run` to preview or `--only claude,cursor,agents` to choose.

## Check your code

```bash
npx @cyberskill/design check            # src, app, components, pages and styles
npx @cyberskill/design check lib docs   # or the folders you name
```

It lists every raw color (hex, `rgb()`, `oklch()`, Tailwind palette classes such as `bg-blue-500`), every raw transition or animation timing (`200ms`, `cubic-bezier()`, `transition: all`, Tailwind `duration-300`), and any second animation library in `package.json` (framer-motion, GSAP, react-spring…), each as `file:line` with what to use instead. It exits 1 when it finds any, so it can run in CI. Git-ignored files and build output are skipped; a line containing `cyberskill-design-allow` is a deliberate exception.

## Why it saves tokens

An agent reads one short index, then only the component files it needs, instead of crawling `node_modules` or guessing from memory. The rules in the index (tokens only, color roles, motion recipes, flat imports, labels, status with icons) prevent the most common review comments, and `check` catches what slips through.

This site also publishes [`/llms.txt`](/llms.txt) and [`/llms-full.txt`](/llms-full.txt) for tools that read the web.
