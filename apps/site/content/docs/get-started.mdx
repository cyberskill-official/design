## Install

```bash
npm install @cyberskill/design @phosphor-icons/react
```

React 19 is required. Charts, tables and form helpers are optional and need their own peer packages (see [Overview](/docs)).

## Next.js with Tailwind 4

```css title="app/globals.css"
@import 'tailwindcss';
@import '@cyberskill/design/tailwind.css';
@import '@cyberskill/design/styles.css';
```

Load the three typefaces (Be Vietnam Pro, Manrope, JetBrains Mono) from the package. They are self-hosted, split into Latin and Vietnamese files the browser fetches only when needed, and tuned so stacked Vietnamese capitals (Ẫ, Ỗ) are never cut off in text inputs:

```css title="app/globals.css"
@import '@cyberskill/design/fonts.css';
```

Loading the fonts another way (`next/font`, a CDN) also works, since the tokens only name the families, but then inputs clip those capitals unless you add the same `ascent-override` yourself.

Tailwind utilities now speak the system: `bg-primary text-primary-foreground`, `border-border`, `text-muted`, `font-display`, `rounded-lg`, `bg-chart-1`.

## Use a component

```tsx
import { Button } from '@cyberskill/design';

export default function Page() {
  return <Button variant="accent">Ask AI</Button>;
}
```

Components work in Server Components files: every export is a flat name (`Dialog`, `DialogContent`…), never `Dialog.Root`.

## Dark mode

Set `data-theme` on `<html>` or on any element:

| Value | Result |
|---|---|
| `light` (default) | Ink & Gold light |
| `dark` | Ink & Gold dark |
| `system` | Follows the operating system |

Themes can be nested: a `data-theme="dark"` panel inside a light page is fully dark.

## Plain HTML

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&family=Manrope:wght@700;800&display=swap">
<link rel="stylesheet" href="https://unpkg.com/@cyberskill/design@3/dist/styles.css">

<button class="cs-button" data-variant="primary" data-size="md">
  <span class="cs-button-label">Save changes</span>
</button>
```

Interactive components (dialogs, menus, selects) need React; static ones (buttons, badges, cards, alerts, tables) work with the classes alone.
