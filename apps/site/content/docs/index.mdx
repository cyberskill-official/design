## What's in the package

| Import | What you get |
|---|---|
| `@cyberskill/design` | React components |
| `@cyberskill/design/styles.css` | Tokens, base styles and component CSS in one file |
| `@cyberskill/design/tokens.css` | CSS variables only, light and dark |
| `@cyberskill/design/tailwind.css` | Tailwind v4 theme mapping |
| `@cyberskill/design/tokens` | Typed token object for charts, emails and native apps |
| `@cyberskill/design/charts` | Chart presets (needs `recharts` 3.8 or newer) |
| `@cyberskill/design/table` | Data table (needs `@tanstack/react-table` and `@tanstack/react-virtual`) |
| `@cyberskill/design/forms` | React Hook Form helpers (needs `react-hook-form`) |
| `@cyberskill/design/date` | Calendar, date, range and time pickers (needs `react-day-picker` and `date-fns`) |
| `@cyberskill/design/utils` | Pure helpers (`cx`, `formatFileSize`, chart colors), safe in Server Components |
| `@cyberskill/design/assets/*` | Logo files |

## Principles

- **Accessible by default.** Behavior comes from [Base UI](https://base-ui.com): focus, keyboard and screen readers work out of the box. Every component is tested with axe in light and dark.
- **Checked, not eyeballed.** The token build fails if text contrast drops below WCAG targets, or if two colors that mean different things look alike, including to color-blind readers.
- **Calm by default, gold for the moment that matters.** Product screens keep gold under 3% of the screen.
- **Works anywhere.** Plain CSS with tokens: Next.js with or without Tailwind, plain HTML, React Server Components.
