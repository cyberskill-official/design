Use this pattern for a product's public website: home, product and landing pages. The header uses a [Navigation menu](/docs/components/navigation-menu) with panels of link cards, and swaps it for a [Drawer](/docs/components/drawer) menu on narrow screens. The hero sets the headline in the display type with a primary and a secondary [Button](/docs/components/button) and a short trust line. Feature [Cards](/docs/components/card) follow, and the footer lists [Links](/docs/components/link) in columns.

## Notes

- Links that navigate are links: "Start free" and "Book a demo" are buttons rendering `<a>` (`nativeButton={false}`), so they open in a new tab and show the URL on hover.
- One primary call to action per view: "Start free" appears in the header and the hero, the same action; everything else is secondary.
- The headline is the page's only `h1`. It scales from 34 to 56px with the width and is balanced so lines break evenly; keep it under about 12 words.
- The phone menu repeats the same links in a drawer named "Menu"; both navs are labelled "Main", and only one is visible at a time.
- Each footer column is its own `nav`, named by its heading, so screen reader users can skip between them.
- Responsive: feature cards go from four across to one; footer columns wrap to two on phones.
