## UI: CyberSkill Design System

All UI uses `@cyberskill/design`. Before writing or changing UI, read `node_modules/@cyberskill/design/ai/INDEX.md` and then only the `ai/components/<name>.md` files you need. Read `ai/motion.md` before adding any animation and `ai/color.md` before choosing any color. Rules: use a component before writing custom UI; add no other UI kit (Radix, shadcn/ui, MUI…); tokens only (no hex or Tailwind palette colors); fill by color role, gold only for on, done or key; animate only through `--motion-*` recipes or `@cyberskill/design/motion`; flat named imports; every control has a visible label; status shows icon + text. Run `npx @cyberskill/design check` before you finish.
