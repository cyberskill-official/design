## UI: CyberSkill Design System

All UI uses `@cyberskill/design`. Before writing or changing UI, read `node_modules/@cyberskill/design/ai/INDEX.md` and then only the `ai/components/<name>.md` files you need. Rules: use a component before writing custom UI; tokens only (no hex or Tailwind palette colors); flat named imports; every control has a visible label; status shows icon + text.
