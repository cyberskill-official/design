# CyberSkill slides

Read the [shared CyberSkill entrypoint](../../../SKILL.md) first, then [design doctrine](../../../docs/doctrine.md). These are the canonical design contract; repository governance and user authorization still apply.

Inspect [the deck kit](../../../ui_kits/deck/) and the relevant [template](../../../templates/). Use the shipped browser interpreter for `.dc.html` preview; check external host capability only for host-specific authoring/export. Establish output requirements from the request, check actual export-tool availability and inspect rendered/exported results. Do not assume editable PPTX or offline behavior from an HTML preview.

Read its inventory and licensing limitations before consulting a resource.
